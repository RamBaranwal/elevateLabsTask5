# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Technologies Used
- HTML
- CSS
- GitHub
- GitHub Pages

## Project Description
Created a responsive static website using HTML and CSS and deployed it using GitHub Pages.

## Deployment Steps
1. Created an `index.html` file.
2. Created a GitHub repository.
3. Uploaded the website files.
4. Configured GitHub Pages to deploy from the `main` branch and root folder.
5. Verified the live website.

## Outcome
Successfully hosted a static website using GitHub Pages.
